# 🦁 XXD Panel 062

### 用稚拙黑线和一枚源图强调色保留照片的聪明瞬间

Panel 062 把复杂照片压缩成一个核心图形与少量辅助符号，以不稳定的黑色手绘线稿、大面积浅色留白和一处源图特征色，形成远看克制、近看亲切的编辑画面。

**关键词：** 稚拙黑线 · 单一强调色 · 聪明笨拙 · 极浅纸底 · 编辑留白

## 使用

```text
/xxd-panel-062 photo.jpg --mode design-only --size 3:4 --text prompt --locale zh-CN
```

支持单图或图片目录、四种输出模式、多尺寸和三种文字模式。完整行为见 [SKILL.md](SKILL.md)。
