# 🦁 XXD Panel 062

### Use naive black lines and an accent color from the source image to preserve the smart moments of the photo

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 062 compresses complex photos into a core graphic and a small number of auxiliary symbols. It uses unstable black hand-drawn line drawings, a large area of light white space, and a characteristic color of the source image to form an editing picture that is restrained from a distance and friendly from close up.

**Keywords:** Childish black line · Single accent color · Clever and clumsy · Very light background · Editorial blank

## Use

```text
/xxd-panel-062 photo.jpg --mode design-only --size 3:4 --text prompt --locale en-GB
```

Supports single image or image directory, four output modes, multiple sizes and three text modes. See [SKILL.md](SKILL.md) for the complete behavior.
